Pocket Friend 💸

Your money. Your friend.

Pocket Friend is a student-focused personal finance companion designed to make money management simple, friendly, and accessible. It helps students track daily expenses, understand their spending habits, and manage their monthly budgets through a simple conversational interface.

💡 Inspiration

Many students find it difficult to track their daily spending and stay within a budget. Small purchases can add up quickly, making it harder to save money.

We built Pocket Friend to make personal finance less stressful and easier to understand, especially for students who are starting to manage their own money.

🚀 What It Does

- Expense Tracking: Record expenses by amount, category, and note.
- Budget Overview: Set a monthly budget and view total spending and remaining money.
- Spending History: Review recorded expenses and explore spending patterns.
- Conversational Assistant: Ask basic questions about spending, remaining budget, and saving.
- Local Data Storage: Store expense records in a local SQLite database.

🛠️ Built With

- Python
- Streamlit
- SQLite
- Pandas

⚙️ How to Run

1. Install Python 3.10 or later.

2. Clone this repository:
   
   git clone https://github.com/vansh1623/Pocket-Friend.git
cd Pocket-Friend

3. Install the required dependencies:
   
   python -m pip install -r requirements.txt

4. Start the application:
   
   python -m streamlit run app.py

5. Open the local URL displayed in your terminal.

🎯 Who Is It For?

Pocket Friend is designed primarily for students and beginners who want a straightforward way to track spending, plan a budget, and develop better financial habits.
